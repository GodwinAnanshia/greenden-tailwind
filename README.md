# 🌿 Greenden – Plant Shopping Website

Greenden is a responsive plant shopping website built using **HTML and Tailwind CSS**. It provides a simple and user-friendly interface for exploring plants, viewing products, and contacting the store.

## ✨ Features

- **Home Page:** Introduction to Greenden with featured products and customer reviews.
- **Products Page:** Displays plant products with names and prices.
- **Product Search:** Search and filter products by name.
- **Contact Page:** Contact form for customer enquiries.
- **Responsive Design:** Adapts to different screen sizes.
- **Hover Effects:** Smooth transitions and animations for product cards.
- **Easy Navigation:** Navigate between Home, Products, and Contact pages.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Visual Studio Code

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser using Live Server.

4. Explore the Home, Products, and Contact pages.

## 🎯 Project Objective

The objective of this project is to practice frontend web development using HTML, Tailwind CSS while creating a clean, responsive, and interactive plant shopping website.
